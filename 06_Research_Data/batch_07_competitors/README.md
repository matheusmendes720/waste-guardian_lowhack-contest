## 🎯 Objetivo deste Batch

Mapear todos os players relevantes do mercado de apps anti-desperdício alimentar para entender a paisagem competitiva e identificar gaps. Responder: "Quem já faz isso, como fazem, e onde o Waste Guardian se diferencia?"

---

## ❓ Perguntas de Pesquisa

- **Q7.1:** Quem são os principais apps globais anti-desperdício (Too Good To Go, OLIO, NoFoodWasted)?
- **Q7.2:** Quais apps brasileiros existem (Comida Invisível, EatWell)?
- **Q7.3:** Qual o modelo de receita de cada um?
- **Q7.4:** Quais funcionalidades cada um tem (gamificação, IA, doação)?
- **Q7.5:** Onde Waste Guardian se diferencia? (matriz de features)
- **Q7.6:** Quais apps B2B (food waste management) existem no Brasil?
