4. **Instituto Natura sem página dedicada** — site principal Natura teve erro 404 em /instituto-natura; consolidado via Wikipedia + Instituto Natura (institutonatura.org.br).
5. **Unilever Brasil site oficial /sustainable-living/ retornou 404** — usei Unilever Global + Hellmann's como referência.
6. **GPA RI oficial (ri.gpabr.com) com erro de transporte** — usei Wikipedia + release imprensa como proxy.
