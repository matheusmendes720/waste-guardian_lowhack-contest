## Q8.3: Quais marcas de supermercado têm iniciativas anti-desperdício?

### Finding 3: Todos os 5 maiores varejistas BR têm programa anti-desperdício, mas tímido

| Varejista | Iniciativa Anti-Desperdício | Escala | Documentada |
|-----------|----------------------------|--------|-------------|
| **Carrefour Brasil** | Linha Imperfeitos (-30%), parceria Food To Save, Mesa Brasil SESC | 1.203 lojas, 28 mi clientes/mês no Atacadão | Wikipedia + RI 2022 |
| **GPA (Pão de Açúcar)** | Linha Taeq orgânicos, frutas "Bonita de Se Ver", Mesa Brasil SESC | 700+ lojas (após cisão 2024) | Wikipedia + RI 2022 |
| **Assaí Atacadista** | Atacadão Solidário (doação Banco de Alimentos), compra imperfeitos | 300+ lojas (atacarejo) | RI 2024 |
| **Sonda (regional SP)** | Programa próprio anti-desperdício | 50+ lojas (SP) | Sem doc oficial — gap |
| **Super Muffato, Savegnago, Mateus, Condor (regionais)** | Iniciativas locais, sem escala nacional | Variável | Sem doc oficial — gap |

### 3 Iniciativas anti-desperdício MAIS relevantes para Waste Guardian:

1. **Linha Imperfeitos (Carrefour)** — vende frutas/vegetais "feios" com 30% desconto. Modelo "ex-post" (desperdício já aconteceu).
2. **Plataforma Solidária (iFood)** — permite restaurantes DOAREM comida excedente via app. Modelo "ex-ante" (evita desperdício).
3. **Atacadão Solidário (Assaí)** — doação de perecíveis para Banco de Alimentos. Modelo "ex-post" (desperdício parcialmente evitado).

### **GAP ENORME:** NENHUM dos varejistas tem solução **DOMÉSTICA** (B2C para household)

- **Carrefour Imperfeitos**: B2B, reduz perda em loja (mercado inteiro)
- **GPA Taeq**: B2B, posicionamento de orgânicos
- **iFood Solidária**: B2B (restaurante → ONG), não para consumidor
- **Assaí Solidário**: B2B, doação a Banco de Alimentos

**Oportunidade Waste Guardian:** Ser o **primeiro app BR que trabalha com consumidor final** (household) para reduzir desperdício DOMÉSTICO, com:
- IA recipes para sobras
- Gamificação para engajamento
- Scan OCR de produtos
- Mapa de doação direta

- **Mídia espontânea (gratuita)** = R$ 0
- **Editais públicos (FBB, FAPESP, FAPEG)** = R$ 30K-100K
- **Match funding (modelo Vale)** = até R$ 1,1M total (Vale + público)
