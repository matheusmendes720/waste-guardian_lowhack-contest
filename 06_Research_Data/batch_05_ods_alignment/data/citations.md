## 6. Metodologia de busca

### 6.1 Estrategia de busca adotada
1. Fontes oficiais governamentais em paralelo (ONU Brasil, IBGE, IPEA, MMA) — tentativa de obter dados primarios
2. Validacao cruzada entre IPEA e IBGE — para confirmar/rejeitar dados
3. Plano de acao para gaps: SESC Mesa Brasil (case de referencia), ONG Banco de Alimentos (case de referencia)
4. Recuperacao da legislacao via Planalto.gov.br (Lei 12.305/2010 e Lei 12.187/2009 citadas)
5. ONU SDG Knowledge Hub para dados globais (referencia para Brasil)

### 6.2 Limitacoes de acesso
- **IBGE ODS Brasil (odsbrasil.gov.br):** Conteudo dinamico JS-only; web fetch nao capturou valores dos indicadores. A pagina inicial confirma existencia do portal mas a busca por indicadores especificos exige JavaScript.
- **MMA (www.gov.br/mma):** Paginas massivas de menu; conteudo principal dos Planos Nacionais exige navegacao adicional ou PDF nao indexado.
- **SESC Mesa Brasil (www.sesc.com.br / www.sescsp.org.br):** Paginainstitucional fragmentada; relatorios anuais 2022/2023/2024 nao encontrados publicamente em URL acessivel. Dados disponiveis: 25+ anos operacao, 19 unidades SP, 1100+ parceiros.
- **Embrapa Publicacao "Desperdicio de Alimentos no Brasil":** URL original nao acessivel. Cifras (23,6 Mt/2019; 27 Mt/2023) obtidas via fontes secundarias (Pacto Contra a Fome, Banco de Alimentos).
- **PlanClima conteudo detalhado (texto do plano):** Pagina principal do MMA confirma existencia; documento integral do plano nao captado via web fetch.

- Inseguranca alimentar 54,7M: IBGE PNAD 2024 (primario) + Banco de Alimentos (citacao secundaria) ✓
- Desperdicio 23,6 Mt/2019: Banco de Alimentos (secundario) + Embrapa 2019 (citado) - corroborado ✓
- Fome global 9,1%/2023: ONU DESA (oficial) ✓
- PNRS marco legal: Lei 12.305/2010 (Planalto) + IPEA 2024 (secundario) ✓
- Retrocesso ODS 2 ate 2022: IPEA 2024 + Banco de Alimentos (corroborado por dados PNAD 2024) ✓
- Estagnacao ODS 11.6 residuos: IPEA 2024 ✓
