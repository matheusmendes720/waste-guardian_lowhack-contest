## 🎥 CHECKLIST DE EQUIPAMENTO

```
NECESSÁRIO:
[ ] Câmera (smartphone moderno 1080p funciona)
[ ] Microfone externo (narrador precisa ser claro)
[ ] Iluminação básica (luz natural de janela ou ring light)
[ ] Fundo neutro (parede branca ou cenário limpo)
[ ] Tripé ou apoio para câmera (estável, sem tremor)
[ ] Screen recording do Figma (protótipo precisa estar pronto)

OPICIONAL (se sobrar tempo):
[ ] Teleprompter (mas ensaiar 3x antes de usar)
[ ] Edição com mograph (After Effects, Canva, Premiere)
[ ] Música de fundo (sem direitos autorais)
[ ] Transições animadas
```

## ✂️ CHECKLIST DE QUALIDADE DO VÍDEO

```
ANTES DE ENVIAR:
[ ] Duração ≤ 5 minutos (cronometrar rigorosamente — limite = 5:00)
[ ] Áudio sem ruído de fundo (testar gravando 30s antes)
[ ] Rosto visível por pelo menos 30 segundos (apresentação)
[ ] Protótipo demonstrado (screen recording do Figma funciona)
[ ] Modelo de negócio explicado (45 segundos)
[ ] Números quantificados (kg, R$, % — não "muito" ou "bastante")
[ ] Sem gagueira ou "ehhh" (ensaiar 3x antes de gravar)
[ ] Fundo neutro (sem bagunça — usar parede branca ou cenário)
[ ] Credenciais no final (nomes, orientadora, escola)
[ ] Link do protótipo mencionável ("experimente em [link]")
[ ] Exportado como MP4 (não MOV, não AVI)
```
